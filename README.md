# Breast Cancer Detection using YOLOv8 + ResNet

## Overview

This project explores a two-stage deep learning approach for detecting and classifying breast tumors from ultrasound images.

The first stage uses **YOLOv8** to detect the location of a tumor in the ultrasound image using a bounding box. The detected tumor region is then cropped and passed to a **ResNet-based classifier**, which predicts whether the tumor is **benign or malignant**.

The overall pipeline is:

**Ultrasound Image → YOLOv8 → Tumor Bounding Box → Tumor Crop → ResNet → Benign / Malignant**

The idea is to separate the problem into two steps: first identify **where the tumor is**, and then determine **what type of tumor it is**.

---

## Approach

### 1. Tumor Detection — YOLOv8

YOLOv8n was initialized using pretrained YOLO weights and then fine-tuned on the breast ultrasound dataset.

The model was trained to identify the location of tumors rather than directly classify them as benign or malignant.

The model produces:

- Bounding box coordinates
- Detection confidence
- Tumor location within the image

The bounding boxes generated by YOLOv8 are then used to isolate the tumor region from the original ultrasound image.

### 2. Tumor Classification — ResNet

A pretrained ResNet model was adapted for the breast ultrasound classification task.
The final classification layer was configured for the target classes and the model was fine-tuned using the transformed ultrasound/tumor images.
The classifier predicts whether the tumor region belongs to the relevant class.

The tumor regions identified by YOLOv8 are used as inputs to a **ResNet-based image classifier**.

The classifier predicts one of two classes:

- **Benign**
- **Malignant**

This allows the two models to perform different parts of the task:

**YOLOv8:** Where is the tumor?

**ResNet:** Is the detected tumor benign or malignant?

---
### Model Training

### YOLOv8

The YOLOv8n model was trained for 20 epochs with an image size of 640 × 640 and a batch size of 16.
The model was initialized from pretrained YOLOv8 weights and fine-tuned on the annotated ultrasound images.
The best-performing model checkpoint was saved and used for subsequent tumor detection.

### ResNet

The ResNet model was trained for 10 epochs using the transformed tumor images.
The pretrained ResNet architecture was adapted for the classification task and fine-tuned on the benign/malignant image data.
The model with the best validation performance was saved and used for the final evaluation and prediction pipeline.

---

## Results

The two-stage YOLOv8 + ResNet pipeline showed promising results on the validation data.

### YOLOv8 — Tumor Detection

| Metric | Score |
|---|---:|
| Precision | 0.842 |
| Recall | 0.775 |
| mAP@50 | 0.863 |
| mAP@50–95 | 0.608 |

The YOLOv8 model was able to identify tumor regions and generate bounding boxes on ultrasound images.

### ResNet — Benign vs Malignant Classification

| Metric | Score |
|---|---:|
| Accuracy | 0.8915 |
| Precision | 0.8333 |
| Recall | 0.8333 |
| F1 Score | 0.8333 |
| **ROC-AUC** | **0.9494** |

The **ROC-AUC of 0.9494** was particularly encouraging, indicating that the ResNet classifier was able to distinguish between benign and malignant tumor regions well across different classification thresholds.

The model achieved approximately **89% validation accuracy**, with precision, recall and F1-score of approximately **83%**.

Class Imbalance
The original dataset is not evenly distributed across the three classes. There are more benign images than malignant images, with normal images making up the smallest group. This imbalance is important because a model can achieve good overall accuracy while still performing less consistently on the minority class. For the benign vs malignant classification task, this means that the malignant class requires particular attention when interpreting precision, recall and F1-score. Addressing this imbalance through techniques such as class-weighting, resampling or targeted augmentation would be an important next step.

## Dataset

The project uses the **Breast Ultrasound Images Dataset (BUSI)**.

The dataset contains ultrasound images belonging to three categories:

- Normal
- Benign
- Malignant

For this project, the data was used to build separate detection and classification components.

Data Transformation
Before training the ResNet classifier, the ultrasound images were transformed into a format suitable for the pretrained network. The detected/cropped tumor regions were resized and converted into tensors, with the appropriate normalization applied before being passed into ResNet.
The YOLOv8 training pipeline also applies the image preprocessing and augmentation required for object detection during training. These transformations help the models learn from variations in the ultrasound images while reducing their dependence on the exact appearance or position of individual training examples.

The dataset is **not included in this repository**. To reproduce the project, download the dataset separately and update the dataset path in the notebook.
